驰声 · 抖音直播互动桥
========================

安装（Edge / Chrome 内核浏览器）
1. 地址栏打开 edge://extensions 或 chrome://extensions
2. 打开右上角“开发者模式”
3. 点击“加载解压缩的扩展”
4. 选择本文件夹（douyin-extension）
5. 打开 https://live.douyin.com/ 并进入自己的直播间
6. 回到驰声软件 → 直播互动，看到“抖音扩展已连接”即成功

使用顺序
1. 先启动驰声软件（双击 启动软件.cmd）
2. 在“直播互动”页测试规则和欢迎语
3. 默认是“建议模式”，只生成回复，不自动发送
4. 确认话术后，再开启“自动发送到抖音”

设置
点击浏览器扩展栏的驰声图标 → 选项，或扩展详情 → 扩展选项。
可设置：
- 软件地址（一般留空自动发现）
- 只监听指定房间号
- 聊天容器 / 消息节点 / 输入框 / 发送按钮选择器
- 调试日志

注意
- 抖音网页结构会更新，若公屏读不到，请在扩展设置里调整选择器。
- 自动发送可能触发平台风控或违反平台规则；请只在自有直播间使用并控制频率。
- 扩展不会绕过登录、验证码或平台安全限制。
- 如果浏览器禁止扩展访问本机地址，请允许扩展的本地网络访问权限。
